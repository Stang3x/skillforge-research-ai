#### E. ✅ wasmerio / Python-Scripts
- **URL:** https://github.com/wasmerio/Python-Scripts
- **Local Path (recommended):** reference-repositories/third_party/wasmerio-Python-Scripts/
- **Summary:** Large community collection (~700+ folders) of small Python automation scripts (file utilities, network tools, data converters, simple GUIs, bots). Actively contributed; good for quick, copyable examples and primers on scripting patterns.
- **Relevance:** Fast source of scripts for automating I/O, ingestion, scraping, and utility helpers useful when building small tooling agents or example pipelines. Great for learning common scripting idioms and discovering quick prototypes to adapt.
- **Caveats:** Community-contributed; many scripts are examples and may not follow security best practices. Review before reuse.

## 🎓 Key Learnings (Accumulated)

### From Anthropics Skills (Complete)

**1. Skills Architecture**
- Skills = Modular knowledge packages
- SKILL.md = Standard format with frontmatter
- Composable and versionable
- Shareable across projects

**2. Instruction Design**
- Clear role definition
- Concrete examples
- Specific guidelines
- Error handling patterns

**3. Production Patterns**
- Document handling (DOCX, PDF, XLSX)
- Error recovery
- Performance optimization
- Quality assurance

**4. Agent Enhancement**
- Skills > Static instructions
- Specialized agent variants
- Skill marketplace potential
- Community sharing

### From Muratcankoylan Context Engineering (Complete) ⭐ NEW

**1. Context Window Management**
- Context ≠ just token count (attention mechanics matter)
- Lost-in-middle phenomenon (middle content loses attention)
- Compression strategies (reduce redundancy while preserving signal)
- Optimization techniques (KV-cache, caching, masking)

**2. Multi-Agent Patterns**
- Orchestrator pattern (one manager, many specialists)
- Peer-to-peer pattern (agents communicate directly)
- Hierarchical pattern (tree of agents)
- Each pattern has specific use cases and tradeoffs

**3. Evaluation Frameworks**
- Direct scoring (rubric-based evaluation)
- Pairwise comparison (bias-mitigated)
- Rubric generation (domain-specific standards)
- LLM-as-Judge automation (evaluate like humans)

**4. Skill Composition**
- Sequential: Plan → Search → Evaluate → Cite
- Parallel: Independent skill invocation
- Iterative: Refine based on results
- Trigger-based: Load skills on demand

**5. System Design Principles**
- Progressive disclosure (load only what's needed)
- Platform agnosticism (patterns portable across systems)
- Conceptual + practical (theory + working examples)
