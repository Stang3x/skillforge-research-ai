### Repository Details
- **Name:** Anthropics Skills
- **URL:** https://github.com/anthropics/skills
- **Stars:** 43.8k | **Forks:** 4.1k
- **Rating:** ⭐⭐⭐⭐⭐ (5/5)
- **Status:** Production-grade, actively maintained

### What It Is
Skills = Modular knowledge packages that enhance agent capabilities

### Core Learnings

1. **Skills Architecture**
   - Self-contained folders with SKILL.md
   - YAML frontmatter + markdown content
   - Composable and versionable
   - Shareable across projects

2. **SKILL.md Format**
   ```yaml
   ---
   name: unique-id
   description: What it does and when to use it
   ---
   # Skill Title
   [Instructions...]
   ## Examples
   ## Guidelines
   ```

3. **Skill Design Principles**
   - Clear role definition
   - Concrete examples (3+)
   - Specific guidelines (5+)
   - Error handling patterns

4. **Production Patterns**
   - Document handling (DOCX, PDF, XLSX, PPTX)
   - Error recovery strategies
   - Performance optimization
   - Quality assurance approaches

5. **Skill Composition**
   - Sequential: A → B → C
   - Parallel: Multiple parallel flows
   - Conditional: Decision gates
   - Iterative: Loop until quality
