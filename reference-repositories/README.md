## 🎯 Most Important Concepts (2 Minutes)

### What Are Skills?
```
Skills = Modular knowledge packages
         
Example: "Research Methodology Skill"
Teaches the agent how to:
  - Plan research properly
  - Identify biases
  - Assess quality
  - Follow standards
```

### Why Do They Matter?
- **Better agents:** Specialized knowledge improves performance
- **Reusable:** Use same skill across projects
- **Shareable:** Build skill marketplace
- **Composable:** Combine skills to solve complex problems

### How Do You Create One?
```
1. Create folder with SKILL.md file
2. Write clear instructions
3. Add 3+ examples
4. Add 5+ guidelines
5. Test with your agent
Done!
```

## 🎓 Sample Skill You'll Create

By following this system, you'll create skills like this:

```yaml
---
name: research-methodology
description: Guides research planning, methodology selection, 
  and quality assessment
---

# Research Methodology Skill

You are an expert research methodology consultant...

[Full instructions...]

## Examples

### Example 1: Literature Review Planning
User: "I need to research AI ethics"
Your guidance:
- Define research question
- Establish criteria
- Plan search strategy
- Set quality thresholds

### Example 2: Identifying Bias
User: "How do I know if my research is biased?"
Your guidance:
- Selection bias patterns
- Publication bias check
- Confirmation bias prevention
- Sampling validation

## Guidelines

- Always ask clarifying questions first
- Follow academic standards
- Identify biases proactively
- Suggest risk mitigation
- Recommend interdisciplinary approaches
```
