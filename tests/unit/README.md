# Unit Tests

This directory contains unit tests for individual components of the SkillForge Research AI system.

## Test Files

- `test_skills_base.py` - Tests for the base skills system (Skill, SkillInput, SkillOutput, SkillRegistry)
- `test_search.py` - Tests for web and academic search functionality
- `test_citation.py` - Tests for citation formatting in various styles
- `test_skill_research.py` - Tests for the research skill
- `test_skill_synthesis.py` - Tests for the synthesis skill
- `test_skill_citation.py` - Tests for the citation skill
- `test_skill_methodology.py` - Tests for the methodology skill
- `test_skill_evaluation.py` - Tests for the evaluation skill

## Running Tests

```bash
pytest tests/unit/
```
